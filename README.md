# Reservas Condominio - Frontend

Interfaz web del sistema de reserva de espacios (piscina, canchas, gym).

## Tecnologías
HTML5, CSS3, JavaScript (ES Modules)

## Ejecutar
Abrir con Live Server (VS Code) o servir la carpeta con cualquier servidor estático.
Requiere que el backend esté corriendo en http://localhost:3000
